آخرین اخبار

    سیم خبری ساکت است. هنوز اولین دریافت خبر اجرا نشده. اکشن «Fetch News» را در گیت‌هاب به‌صورت دستی اجرا کنید یا منتظر اجرای زمان‌بندی‌شدهٔ بعدی بمانید.
    دسترسی به فید ممکن نیست. این صفحه باید از طریق یک سرور (مثلاً GitHub Pages) بارگذاری شود تا فایل داده خوانده شود؛ باز کردن مستقیم فایل کار نمی‌کند.

    دربارهٔ استارت‌استار وایر

    استارت‌استار وایر یک فید خبری خودکار است که تازه‌ترین سرخط‌ها را از فهرستی ثابت از ناشران خبری مستقل و معتبر بین‌المللی دریافت می‌کند و تقریباً هر ۱۵ دقیقه یک‌بار به‌روزرسانی می‌شود. هدف این پروژه نمایش خبر در کنار زمینهٔ لازم برای قضاوت دربارهٔ اعتبار آن است، نه جایگزینی خودِ خبرنگاری.

    هر خبر دو نشانهٔ مستقل دارد. «اعتبار ناشر» بر اساس رتبه‌بندی نهادهای مستقل ارزیابی رسانه مانند Ad Fontes Media، Media Bias/Fact Check و AllSides تعیین می‌شود، نه نظر شخصی این پروژه دربارهٔ منبع. «برچسب راستی‌آزمایی» هم نتیجهٔ جست‌وجوی زنده در API ابزارهای راستی‌آزمایی گوگل است که فقط زمانی حکمی نشان می‌دهد که یک راستی‌آزمای حرفه‌ای واقعاً همان ادعای مشخص را بررسی کرده باشد؛ بیشتر خبرهای تازه صادقانه با برچسب «بررسی‌نشده» نمایش داده می‌شوند، نه یک حدس تصادفی.

    این پروژه متن‌باز است و روی گیت‌هاب اکشنز و گیت‌هاب پیجز ساخته شده، بدون ردیابی کاربر و بدون تبلیغات.

    روش رتبه‌بندی‌ها

    «اعتبار ناشر» بازتاب ارزیابی نهادهای مستقل رسانه‌ای (Ad Fontes Media، Media Bias/Fact Check و AllSides) است، نه نظر شخصی این پروژه دربارهٔ یک منبع.

    «برچسب راستی‌آزمایی» از API ابزارهای راستی‌آزمایی گوگل گرفته می‌شود که بررسی‌های موجود (ClaimReview) از راستی‌آزمایان حرفه‌ای را نشان می‌دهد. بیشتر خبرهای تازه هنوز بررسی نشده‌اند؛ این وضعیت طبیعی است، نه نشانهٔ خرابی. «بررسی‌نشده» یعنی هنوز هیچ راستی‌آزمایی برای همان ادعای مشخص منتشر نشده است.
